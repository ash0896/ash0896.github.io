# Ashish Tamhankar — Personal Website

This is my personal academic/portfolio website, showcasing my background as a computational chemist, research experience, publications, and portfolio of projects in computer-aided drug design, molecular modelling, and machine learning.

🔗 **Live site:** [https://ash0896.github.io/](https://ash0896.github.io/)

> ✨ **Note:** This website was "vibe coded" — built collaboratively with an AI assistant (Claude Sonnet 5) through natural conversation rather than hand-written from scratch. I provided the content (CV, research background) and design preferences, and the AI generated the HTML/CSS/JS structure, which I then customized, deployed, and iterated on.
